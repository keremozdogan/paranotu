# ParaNotu — İçerik Haritası (120 yazı + sözlük)

Onaylanan yapı: **8 ana kategori × 15 yazı = 120**, artı çapraz kesen **Sözlük**.
URL deseni: `/<kategori>/<slug>` — `/blog/` katmanı kaldırılıyor.

**Sütunlar:** `Niyet` = arama amacı (Öğrenme / Hesaplama / Karşılaştırma / Karar / Problem çözme).
`İlgili` = iç link verilecek yazılar (`E-1` = Ekonomi 1, `KF-4` = Kişisel Finans 4 …).
`MEVCUT` = bugün sitede olan içerik; sıfırdan yazılmayacak, yeni yapıya taşınacak.
